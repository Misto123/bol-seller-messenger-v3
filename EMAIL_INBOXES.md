## 🔧 Troubleshooting

### Can't access inbox?
- Check URL is correct (rebdev.nl/mailbox/XX)
- Clear browser cache
- Try incognito/private mode

### No replies showing?
- Check all inboxes (replies could be in any)
- Check History page for which email was used
- Allow 24-48 hours for seller response

### Too many emails?
- Set up email filters in rebdev.nl
- Archive old conversations
- Focus on recent campaigns only
